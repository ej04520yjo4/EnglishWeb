# A2 第十單元試行 QA：綜合郵件、行程與生活故事

## 四課內容

| 課程 | 核心句 | 繁中 |
|---|---|---|
| 1. 回信開頭表達感謝 | Thank you for the email. | 謝謝你寄來的電子郵件。 |
| 2. 讀懂出發時刻 | The bus leaves at ten on Saturday. | 公車星期六十點發車。 |
| 3. 確認見面地點 | I can meet you at the station. | 我可以在車站跟你見面。 |
| 4. 回顧行程的變化 | I missed the bus, so I took the train. | 我沒趕上公車，所以改搭火車。 |

每課有逐字拼寫、句子重建、一題閱讀辨識、兩題換字及一題情境選答。第四課後把四句行前回信與兩句行後紀錄重建，再答四題閱讀理解；單元測驗包含四個核心句。

回信先道謝，說明公車發車時刻、約在車站見面，最後邀請對方一起吃晚餐。行後紀錄說明沒趕上公車後改搭火車，以及晚餐後回家。理解題分別問致謝原因、出發時間、見面地點與實際改搭的交通工具。

## 字彙與語塊

- 新 lexeme：`thank`、`email`、`miss`。`missed` 是 `miss` 的過去式，在這裡是「沒趕上」；`took` 沿用 `take` 的詞條。
- 新語塊：`thank-you`、`leaves-at-ten`、`missed-the-bus`、`took-the-train`。每個作答格仍只填一個字。
- `thank` 與 `email` 用既有 CMUdict 候選；`missed`、`took` 為待人工複核的美式音標標記。所有新音訊欄位仍是 `pending`，未交付新音檔。
