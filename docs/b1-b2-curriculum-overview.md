# B1／B2 試行課程總覽

## 發布狀態

B1 與 B2 已建立完整的試行資料，每個程度均有 8 單元、32 課。所有列與附加練習維持 `pilot_review_required`，catalog 狀態目前為 `disabled`。資料會繼續接受產生器、ID、結構與課程稽核，但不由一般啟動流程載入，也不出現在程度選擇器。

目前執行期只提供 A1 與 A2；設定中的「顯示進階試行課程」只能顯示 A2 QA，不得繞過 B1／B2 的 disabled 狀態。B1／B2 人工內容審核里程碑暫停，待 A1/A2 詞彙與內容基礎完成後再決定是否恢復。

## B1 獨立運用

- 來源：`public/data/b1-course-v1.csv`
- 規模：8 單元、32 課、249 個逐字作答位置
- 練習：32 題閱讀辨識、64 題句型換字、32 題文字選答
- 文章：8 篇四句短文、32 題閱讀理解
- 單元：經驗故事、目標計畫、意見理由、工作學習溝通、旅行協調、媒體科技、人際社會、整合敘事

## B2 中高級運用

- 來源：`public/data/b2-course-v1.csv`
- 規模：8 單元、32 課、298 個逐字作答位置
- 練習：32 題閱讀辨識、64 題句型換字、32 題文字選答
- 文章：8 篇四句短文、32 題閱讀理解
- 單元：深入觀點、方案比較、職場回饋、新聞公共議題、文化差異、科技環境社會、提案協商、整合評論

## 資料原則

- 每個 `answer` 只含一個英文單字；多字語意保存在 `chunk_*`。
- 屈折變化共用字典原形 `lexeme_id`，句中用法使用 `sense_id`。
- 每課包含核心句、語塊、句型、兩題換字、閱讀辨識與文字選答。
- 每單元第四課完成後進入文章重建與閱讀理解。
- 音訊狀態目前為 `pending`，播放只可使用既有 Web Speech API 備援。
- `scripts/create-b1-b2-curriculum.mjs` 是可重現產生器；正式載入來源仍是 catalog 宣告的 CSV／JSON。

## 人工 QA 清單

逐課檢查英文自然度、台灣繁中、詞性、語意提示、語塊邊界、句型名稱、干擾選項、文章連貫、CEFR 難度及 KK／IPA。未完成這些檢查前，不得把 B1 或 B2 改為 `pilot`、`production` 或 `human_reviewed`。
