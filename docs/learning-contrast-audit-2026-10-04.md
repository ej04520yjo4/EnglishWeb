# 學習畫面對比檢查

## 範圍與基準

以 `main` 的 `28b41d0` 為基準，針對首頁主要操作、逐字輸入、單字詳情、句子重組及閱讀選答補強對比。保留暖色調、版型、字級、課程資料與進度規則。

採用 [W3C 文字對比說明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 的一般文字 4.5:1 門檻，包括 placeholder、hover 與 focus 文字；輸入框及鍵盤焦點使用 [非文字對比說明](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html) 的 3:1 門檻。顯示時的數值可四捨五入，但測試以未四捨五入值判定。

這是限定範圍的檢查，不是完整 WCAG 合規認證。停用控制項、純裝飾與商標不列入一般文字門檻；答題後的答案仍是重要資訊，即使選項已不能點選，也繼續檢查文字可讀性。

## 配色修正

- 共用次要文字採用既有「相關字詞」頁較深的 `#5b6678`，不再只限單一頁面。
- 裝飾仍保留亮珊瑚色；主要按鈕使用 `#b1442e`，hover 使用 `#973b29`。白字分別為 5.62:1 與 7.06:1。
- 詳情按鈕的 `Enter` 標籤改用透明黑底，避免白色半透明底再次降低白字對比。
- 主要操作按鈕只對滑鼠移入相關屬性套用動畫，鍵盤焦點外框立即出現，不再從透明色淡入。
- 一般輸入框、重組格與選項邊框使用 `#8b837b`；對白底為 3.73:1。placeholder 使用次要文字色，明確指定 opacity 1。
- 正確與待修正文字分別採用 `#27673c`／`#8e5d14`，在各自淡綠／淡黃底為 6.17:1／5.26:1；邊框也採用較深的綠／褐色。原有文字回饋保留，不靠顏色獨自表示結果。
- 主題色、頁面排列、字級、按鈕尺寸、課程 CSV／JSON、答題流程與 localStorage schema 都不變。

## 瀏覽器檢查方式

`tests/e2e/learning-contrast.spec.ts` 透過正式頁面操作課程，不以注入 DOM 或原始碼比對代替學習流程。桌面 1440×900 與手機 375×812 各三項，檢查首頁按鈕、課程導言、逐字回想、單字詳情、重組的混合正確／錯誤與三次揭示、結果頁，以及閱讀選答的選取／正確／錯誤狀態。

`tests/e2e/helpers/contrast.ts` 從瀏覽器 computed style 計算相對亮度，合成半透明色層與 placeholder opacity；遇到未支援的漸層、背景圖或群組 opacity 會直接失敗，不假裝已通過。文字使用控制項內部實際底色，正 outline-offset 的焦點外框使用外側父層底色；邊界檢查以控制項填色為相鄰色。這不是任意 CSS 合成效果或整頁內容的通用檢測器。

Focused 檢查已實際通過 6/6，exit 0。滑鼠移入測試等待該動畫結束後量測，焦點外框則仍立即檢查；焦點文字測試會先移開滑鼠，避免混合兩種狀態。第一次測試的翻譯 selector 歧義已更正；第二次找到的實際焦點淡入問題已修正，沒有以放寬對比門檻略過。全套瀏覽器測試 132/132 通過（桌面／手機各 66），品質檢查 183 項單元測試通過，exit code 均為 0。詳細全案結果記錄於 `PROGRESS.md`。
