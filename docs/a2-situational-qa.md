# A2 第 14–31 單元：實用情境試用

這些單元延續原本的逐字輸入、語塊理解、句子重建、閱讀辨識、兩題換字與情境選答。每個單元有四課、短文、四題閱讀理解和單元測驗。

| 單元 | 情境 | 核心句例 |
|---|---|---|
| 14 | 退換貨與尺寸 | Do you have it in a smaller size? |
| 15 | 交通延誤與改搭 | Can I use this ticket on the bus? |
| 16 | 工作回報與交接 | Could you check the file before lunch? |
| 17 | 問路與地標 | The library is across from the school. |
| 18 | 裝置故障與求助 | My computer will not turn on. |
| 19 | 遺失物品與領回 | Where can I pick it up? |
| 20 | 圖書館借書與期限 | When is the book due? |
| 21 | 改約與核對時間 | Friday afternoon works for me. |
| 22 | 表達偏好與一起決定 | I prefer tea to coffee. |
| 23 | 餐點成分與替代選擇 | Can I have it without meat? |
| 24 | 延長時間與回覆期限 | I can finish it by Friday. |
| 25 | 敘述經過與後續行動 | The store was already closed. |

## 用法對照

- 商店的 `return` 是退回商品；在圖書館是還書；向鄰人借物可用 `bring it back` 承諾歸還。
- `check` 在餐廳可以是帳單，在工作中用作檢查動詞，`check the weather` 則是查天氣。
- `works` 可指裝置正常，也可表示日期可行。進度為同一 `work` 詞條，但課程提示按情境區分。
- `before lunch` 不含午餐當下；`by Friday` 可包含星期五。所有涉及交通票、餐點、設備與請假的短文都是模擬對話，不是業者規定、技術指南或醫療建議。
- `write` 與 `right` 同音，分別練習「寫」和「向右」。`receipt` 的 p 不發音；`sent`、`lost`、`got` 和 `was` 保留原形詞條及各自的詞形音標。

## 試用順序

- 一般模式通過前一個單元測驗後進入新單元；可在設定開啟進階試行直接試做。試行開關不會替你補上通過紀錄。
- 建議先試第 14、19、21、25 和 29 單元，確認確認對象、時間、金額與行動等資訊是否清楚。短文選項須可由原文支持，並涵蓋跨句理解。
- 正式英語、台灣繁中、程度難度以及 KK／IPA 候選仍需人工複核；本批未交付新增錄音。完成試行不代表正式通過 A2，也不會啟用 B1 或 B2。
