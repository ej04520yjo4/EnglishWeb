# KK 音標音訊來源

KK 音標頁使用 Wikimedia Commons 的免費、可自由使用錄音，不再以瀏覽器朗讀例字代替音標。每張音標卡的「錄音來源與授權」會連回原始檔案頁；完整機器可讀清單位於 `public/data/kk-audio-attribution.json`。

## 使用原則

- 母音優先使用單獨母音錄音。
- 美式 KK 的 `[e]`、`[o]`、`[aɪ]`、`[aʊ]` 使用對應的美式單獨聲音。
- 短促塞音與部分子音無法自然延長，來源錄音可能加入簡短的 `[a]` 載音以便辨認；這不是畫面例字的朗讀。
- `[ɝ]` 與 `[ɚ]` 的主要差別是重音。兩者單獨發音時非常接近，目前共用同一個開放授權捲舌母音樣本，並在教學提示中說明重讀與非重讀差異。

## 授權與更新

來源包含 Public Domain、CC0、CC BY-SA 3.0 與 CC BY-SA 4.0。重新產生來源清單時，可執行：

```powershell
.\scripts\download-kk-audio.ps1
```

若日後要將音檔保存到 `public/audio/kk/`，可加上 `-Download`；下載前應遵守 Wikimedia 的流量限制。更新來源時必須保留作者、原始頁面與授權網址。
